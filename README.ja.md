# ccdig

Claude Code の会話履歴から、依頼文・返答・ツールの呼び出し・ツールの結果を
種類ごとに掘り出す CLI です。

[English](README.md)

## 何をするか

Claude Code はセッションを `~/.claude/projects/` 配下に JSONL で保存します。
そこには、人間が打った依頼文と、ハーネスが書いた行が混ざっています。
ツールの呼び出しとその結果、注入されたスキル本文、`<system-reminder>`、
タスク通知、コンパクションの要約、サブエージェントのやり取りです。

ccdig はこの履歴を読み、1 種類ずつ取り出して出力します。

- **依頼文**: 人間が打ったもの。ハーネスのノイズを除き、スラッシュコマンドは
  `/command args` の形に戻す
- **返答**: assistant のテキスト
- **ツールの呼び出し**: 入力の JSON 付き
- **ツールの結果**: 対応する呼び出しと組にして出す

どの種類も、期間・プロジェクト・正規表現・セッション・ブランチの同じ
絞り込みが使え、秘密情報は既定でマスクされます。

## 既存ツールとの違い

セッションを丸ごと読むのは、ビューアや変換ツールが得意です。
ccdig は全セッションから一部を抜き出すための道具です。今週頼んだこと、
失敗した `Bash` の呼び出し、あるキーワードに触れた返答などを取り出せます。
人間が打った依頼文を判定し、既定でマスクし、`jq` につなげる JSON Lines を
出力し、単一のバイナリで動きます。

## 始め方

Rust 1.99.1 以降が必要です。

```sh
cargo install --locked --git https://github.com/tsukuboshi/ccdig
ccdig prompts --since 2026-10-05 --until 2026-10-11
ccdig results --tool Bash --errors --subagents
```

コマンドとフラグ、出力スキーマ、依頼文の判定ルール、マスクの対象は
[README.md](README.md) を参照してください。

## 注意

- マスクは特徴的なプレフィックスを持つ形式と、`password=` や `api_key:` のような
  認証情報らしい名前への代入だけを対象にしています。それ以外の秘密情報は残ります
- `results` には、ツールが読んだファイルの中身・環境変数・コマンドの出力が
  そのまま入ります。マスクは安全網として扱い、出力を外に出す前に中身を
  確かめてください
- Issue に実際の会話履歴を貼らないでください。再現には合成した JSONL の
  行を使ってください
